No framework, runtime fetch, database, server Function or new runtime dependency. Audit scripts exclude the unpublished partials rather than counting them as pages. Build/tests verify synchronisation and the complete standard/exception classification.

**Homepage work.** The masonry gallery becomes an even editorial grid of the **same twelve existing pieces**, with three evidenced categories: Websites, Branding and Graphic Design.
